#
# THE PAIRING RULE: stored = detent index - 1. Line n below (counting only
# value lines) is the displayed gate for stored value n-1. This was confirmed
# directly for stored 0-63 and at eight probe points above it; it is not an
# assumption.
#
# Method: one note per step on Track 2 pattern 1, steps 1-64, gate ascending
# one detent per step from the encoder minimum -- one export, not one per
# detent. Detents above 64 are covered by the pattern-2 boundary probes rather
# than transcribed individually; see PROVENANCE below.
#
# Format: a "melodic" or "drum" line opens a section; every line after it is
# one displayed value, in detent order, lowest first. Blank lines and lines
# starting with # are ignored. Record a non-numeric extreme literally -- TIE,
# HOLD, inf -- rather than normalising it to a number.
#
# THE VALUES BELOW ARE THE DEVICE'S 2-DECIMAL RENDERING, not the exact
# quantity. The underlying gate lengths are exact binary fractions of a step,
# rounded half-to-even for display -- which is why 0.625 shows as 0.62 while
# 0.875 shows as 0.88. Recover the exact value from the run structure:
#
#     stored   0- 7   0.0625 -> 0.5    step 1/16
#     stored   8-27   0.625  -> 3      step 1/8
#     stored  28-47   3.25   -> 8      step 1/4
#     stored  48-95   8.5    -> 32     step 1/2
#     stored  96-127  33     -> 64     step 1
#
# The device also pads to two decimals in some ranges (4,50) and not others
# (3,5), and uses a comma as the decimal separator. Neither changes the value;
# the values here are normalised to a point separator with trailing zeros
# stripped.
#
# PROVENANCE -- do not lose this distinction:
#   measured  stored 0-35, 37-63   (T2.1, transcribed detent by detent)
#   measured  stored 63,64,79,95,96,126,127 and 0   (T2.2 boundary probes)
#   derived   stored 36            (T2.1 note over-turned one detent; display
#                                   was transcribed, stored pairing is
#                                   positional. Bracketed by measured 35=5 and
#                                   37=5.5 in a confirmed 0.25 run. ONE extra
#                                   note at display 5.25 closes it.)
#   derived   stored 65-78, 80-94, 97-125   (enumerated from the observed
#                                   increment rule, count-verified: any
#                                   miscount would move the maximum off 127,
#                                   and it does not.)
#
